# Contributing to Orea

First off, thank you for considering contributing to Orea! This project is maintained solo, and every bit of help — code, design, documentation, or feedback — genuinely makes a difference.

Orea has three parts you can contribute to independently:
- **orea-ui** — the component library itself
- **orea-tokens** — the design token system (colors, spacing, typography)
- **orea-skill** — the AI skill that helps coding assistants generate consistent components
- **Documentation & showcase** — no code required, just an eye for detail

You don't need to be an expert in all of them. Pick whichever matches your strengths.

---

## Ways to Contribute (No Code Required)

If you're not a developer, or just don't have time to write code, these are just as valuable:

- **Showcase images/GIFs** — record a short clip of a component in action and open a PR adding it to the README or docs site
- **Report bugs by device/browser** — if something looks broken on your setup, open an issue with your device and browser name
- **Improve documentation** — fix unclear wording, add missing examples, or write a usage guide for a component
- **Share a project you built with Orea** — open a PR to add it to the Showcase section

## Ways to Contribute (Code)

- **New components** — build a new animated component following the existing design tokens
- **Bug fixes** — check open issues labeled `bug`
- **Improve orea-skill** — help make the AI skill generate more consistent output
- **Accessibility improvements** — keyboard navigation, ARIA labels, screen reader support

---

## How to Submit a Contribution

1. Fork the repository
2. Create a branch: `git checkout -b your-feature-name`
3. Make your changes
4. If adding a component, make sure it uses the existing design tokens (see `orea-tokens`) for colors, spacing, and typography — this keeps everything visually consistent
5. Open a pull request with a short description and, if visual, a screenshot or GIF

## Reporting Issues

When reporting a bug, please include:
- Device (e.g. Android, Desktop)
- Browser and version (e.g. Chrome 126, Edge 125)
- Steps to reproduce
- Screenshot if possible

## Recognition

Every contributor is credited in the repository. If you contribute a component, showcase example, or significant docs improvement, your name/link will be added to the project's contributors list.

## Questions?

Open a discussion on GitHub or reach out at info@orea.ink. This project is still early, and honest feedback — including criticism — is always welcome.
